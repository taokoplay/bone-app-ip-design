# before.click 案例证据

> 研究时间：2026-08-07。范围为首页、Explorer、Insights 与跨品类代表案例的系统抽样，不是对动态站点逐页穷举。这里只保存案例事实、反例和来源；执行规则以对应 workflow reference 为准。学习模式，不复制受保护的素材、角色、文案或构图。

## 站点事实

- before.click 策展 ASO screenshots、Onboarding、Paywall 与 App Icon，并支持按品类浏览。
- 案例详情通常包含 Icon、产品介绍、评分、更新时间、App Store 外链及整套商店图。
- 官方 Insights 提出：`Screenshots are ads, not documentation.`
- 其默认建议是：主利益、差异、信任、核心功能、更新/活跃度；每张截图有可扫读 caption。
- 这些是策展站方法和样本观察，不等同于 Apple 平台审核规范。

## 代表案例观察

| 案例 | 可观察事实 | 启发与边界 |
|---|---|---|
| Waterllama | 羊驼 Icon 同时表达角色与饮水动作；套图用奖项、角色、Widget、挑战和连续记录 | Character 可执行产品动作；强且可核验的背书可以前置 |
| Tolan | Icon 偏品牌文字与世界观色块；多个角色推动陪伴、任务、洞察、换装和社交 | 多角色体系不必锁死单一头像；关系价值可先于功能名 |
| Headspace | 极简橙色圆形长期作为超级符号；黄橙色贯穿套图 | IP 可以是极简抽象符号，不一定是复杂吉祥物 |
| Flighty | 飞机贯穿 Icon、3D 场景和功能叙事 | 核心物件可成为 Object IP |
| (Not Boring) Camera / Weather | 高对比、局部裁切、物理材质和跨页悬念；天气使用抽象几何 | 形状、材质和运动规则可成为 System IP |
| Gentler Streak | 设备、数据、插画和隐私机制交替；颜色按章节推进 | 敏感产品可把具体隐私机制作为独立证据页 |
| Amie | 无框 UI 卡片拼贴、低噪音排版、利益文案 | UI 足够精致时可去设备框；不适合掩盖未成型 UI |
| UGLYCASH | 黑白、涂鸦、荧光贴纸反转传统金融视觉 | 一致的品牌态度可策略性反品类，但不等于可以削弱可信度 |
| Polestar | App 继承强母品牌，没有另造卡通角色 | 强母品牌优先，避免为年轻化硬加吉祥物 |
| Minimalist Launcher | 文字型 Icon 与反干扰立场一致 | 文字 Icon 是低频策略，需要把字形当图形验证 |

## 高频模式

- 小尺寸常只有一个主识别机制和有限辅助关系。
- 高对比、清晰轮廓和稳定块面通常比高细节更可靠。
- Icon 与商店图共享视觉 DNA，但不必复制同一画面。
- 商店图按销售任务组织，而不是按导航栏顺序展示 UI。
- 标题表达用户结果，UI、数据和真实场景负责证明。
- 角色类产品让角色执行、反馈或成长，而不是每页站在角落。
- 设备框、无框 UI、局部裁切、结果图和证据页交替，可形成视觉节奏。
- 奖项、用户量和媒体评价只有在真实、相关且可核验时才构成信任。

## 有价值的反例

- **Tolan**：多角色体系的 Icon 可以是品牌/世界观，而非单角色头像。
- **UGLYCASH**：专业不必等于蓝色盾牌，但反品类必须靠全系统一致性支撑。
- **Minimalist Launcher**：文字 Icon 可以成立，但不是通用默认。
- **Polestar**：已有强母品牌时，不需要另造 App 吉祥物。
- **Flighty**：没有拟人角色，核心物件仍可承担 IP 职责。
- **Not Boring Weather**：抽象物理系统可以比通用天气 Glyph 更有拥有权。

## 常见失败样本模式

- 原始 UI 截图相册，没有标题和叙事任务。
- 首图同时塞入利益、功能、奖项、角色和 CTA。
- 用 `AI Chat / Widgets / Insights` 等功能名冒充用户利益。
- 每页都是同尺寸手机模板。
- 角色只作角落贴纸，或角色很强但看不出 App 用途。
- 核心价值藏在 UI 小字中。
- 随机换色，没有章节语义。
- 连续画布使单页无法理解。
- Preview 像品牌广告，却不展示真实操作结果。
- 标题本地化，但 UI、日期、单位和对白没有同步。
- 隐私、奖项、用户量和效果声明无法核验。
