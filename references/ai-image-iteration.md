# AI 图片迭代协议

当需要生成或编辑角色、Icon、商店视觉时读取。默认使用当前会话可用的高质量图片生成 Skill；用户指定模型时遵守指定 Skill 的凭据、成本和输入规则。

## 1. Identity Lock

只从用户已确认的母版继续，锁定：

- 轮廓与比例
- 脸部/核心结构坐标
- 主识别机制与次级确认特征
- 结构组件和连接
- 表现媒介、材质和颜色职责
- 允许变化与 Never change

无确认母版时，明确是“探索图”，不能升级为视觉事实源。

## 2. 单轮变量

每轮默认只验证一个主变量；允许一个与主变量强耦合的从变量，但要写明因果关系和判断标准。不要同时换脸、比例、材质、服装和背景。

Prompt 顺序：

```text
Asset type / product context
Identity lock
Single primary change
Coupled secondary change, if any
Material and palette roles
Display context and target sizes
Likely misreadings / negative constraints
Output views, numbering and comparison rule
```

## 3. 失败回退

- 像别的对象/动物：描述造成误读的结构，不只写“不要像 X”。
- 表情媚态：移除眼线、上扬和狭长结构，改眼位、斜率和圆钝度。
- 品牌色突兀：从大色块降为结构、滚边、微光或局部重复。
- 材质跑偏：明确表面粗糙度、边缘和反光模型，并排除相邻材质。
- 身份漂移：回到最后确认母版，不用失败图继续递归。

连续多轮漂移不是固定平台规则；通常 2–3 轮即可判断路径有问题。停止自由重绘，改用母版 img2img、mask 或局部编辑。

## 4. 证据和版本

每个版本保存：编号、短名称、Prompt、输入路径、输出路径、模型、参数、生成时间、费用/积分（可得时）、变更变量、用户结论和事实源状态。

状态只能是：

- 探索
- 待用户确认
- 已确认事实源
- 淘汰（仅保留结论）

不覆盖旧图，不把最新图自动视为最佳图。

## 5. 工具诚实性

- 已实际生成、缩放或联调：标记“已验证”。
- 只根据文字判断：标记“基于输入推断”。
- 缺生图、浏览或图像处理能力：标记“待工具执行”。
- 需要方向选择：标记“待用户确认”。

不要用代码、SVG 或手工拼图冒充用户期待的角色美术；用户明确要矢量生产稿或可编辑结构时例外。
